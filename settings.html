The sheet must be shared as Anyone with the link can view. Use Check sheet to confirm every tab and column below can be found.

    Columns

    The header text in row 1 of each tab, for each piece of data the site uses. Matching ignores capital letters. Fields marked * are required. After a check, each box suggests the headers found on that tab.

    Save

    Save on this device applies the settings in this browser straight away, so you can try them out. To change the site for everyone, click Download site-config.js and replace site-config.js in the site's GitHub repository with it (or ask Claude to commit it).
